Lehrveranstaltungen, aus denen funktionierende Systeme entstanden

Die zweisemestrige Engineering-Design-Sequenz führte zu meiner Bachelorarbeit und dem Forschungswerkzeug für GitHub Issue Tracking. Weitere Kurse führten zu Career Diaries, einer relationalen Mehrrollenplattform, einem Spring-basierten E-Commerce-System, einer Computer-Vision-Pipeline, einem MIPS-Assembler und einer vernetzten Python-Anwendung.
